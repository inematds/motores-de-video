Em resumo

Este repositório é um índice: ele explica, em uma página, cada motor que o INEMA usa para produzir vídeos — explicativos, reels, radares diários, vídeos feitos em código. Serve para quem quer saber qual motor usar, ou estudar um deles. Cada motor tem o que faz, para que tipo de vídeo serve, o formato, se usa avatar, como é acionado, o link do código e até 3 vídeos reais publicados no YouTube. Para ler, não precisa instalar nada.

O que é

Um mapa dos motores, com prova

Nenhum código de motor é copiado aqui. Cada cartão aponta para o repositório do próprio motor e para vídeos que ele já produziu.

🗂️ Um índice, não um motor

O que cada motor faz, em linguagem simples, com formato, avatar e acionamento.

▶️ Até 3 exemplos reais

Vídeos públicos, recentes e variados, tirados do histórico de publicações. (59)

🔄 Atualiza por script

Um comando relê o histórico e regrava a lista de exemplos, o README e esta página.

Como manter esta página em dia

Os comandos rodam na máquina que publica os vídeos, onde está o histórico de publicações. Fora dela o script avisa e mantém o motores.json como está.

1

Baixe o repositório

Precisa de Python 3 e git. O ffprobe (do FFmpeg) é opcional: ajuda a descobrir se cada vídeo é 16:9 ou 9:16.

git clone https://github.com/inematds/motores-de-video
cd motores-de-video
2

Motor novo? Descreva no catalogo.json

Acrescente o motor com o texto em português e a regra que identifica os vídeos dele (pasta de origem ou canal). Use "excluir" para tirar um vídeo e "fixar" para escolher um.

"regras": {"origem": ["/meu-motor/edicoes/"]}
3

Traduza só o que é novo

Os textos em inglês e espanhol ficam em i18n/. O script chama o tradutor central do INEMA (inema-traduz) só para as chaves que faltam.

python3 traduzir.py
4

Releia o histórico e gere tudo

Escolhe até 3 vídeos públicos, recentes e variados por motor, grava o motores.json e regrava os 3 READMEs e as 3 páginas.

python3 atualizar-exemplos.py
5

Publique

Confira a página e envie. O GitHub Pages publica sozinho a partir da branch main.

git add -A && git commit -m "exemplos atualizados" && git push
