In brief

This repository is an index. It explains, on one page, each engine INEMA uses to make videos: explainers, reels, daily radar updates, and videos made with code. Use it to find the right engine or learn about one. Each engine entry explains what it does, what kind of video it is for, its format, whether it uses an avatar, how it is triggered, links to its code, and up to 3 real videos published on YouTube. You don’t need to install anything to read it.

What it is

A map of the engines, with proof

No engine code is copied here. Each card links to the engine’s own repository and to videos it has already produced.

Words that appear on the cards

Nei
Nei Maldaner, creator of INEMA. His avatar (a digital version that speaks the script) presents most videos.
HeyGen
A service that generates videos of the avatar speaking. INEMA uses the site's studio with a subscription.
inemaccbot
INEMA's Telegram bot that runs some engines with a command, such as /r7ex or /explicavideo.
Timer
An automatic schedule on the computer that produces the videos: the engine runs on its own at the scheduled time.
Queue
A list of ready-to-publish videos released gradually, one at a time, at the right time.
Skill
A set of instructions that teaches Claude Code (or Codex) how to do a type of task.
Central translator
INEMA's command that handles all translations through the subscription, with no paid API.
Publishing history
The record that the YouTube publishing tool (yt-pubx) saves for each video uploaded.
Terminal and agent
A terminal is the computer’s command window; an agent is the AI (Claude Code or Codex) that runs in it and starts the engine when you ask.
INEMA TDS, FTD, TIA, Tec… channels
INEMA’s YouTube channels; each engine publishes to the channel for its topic (technology, finance, climate, sports, adventures).
INEMA.CLUB and PRO
INEMA.CLUB is INEMA’s free portal for courses and projects; PRO is the area with the full catalog and search.

How it works

Where the data comes from

The text for each engine is written by hand. The examples come from a script that only reads local files.

catalogo.json→atualizar-exemplos.py→motores.json→gerar.py→README + guide PT/EN/ES→git push→GitHub Pages
For index maintainers · step by step

How to keep this page up to date

You don't need to install anything just to read this page. These steps are for index maintainers. New examples only appear on the machine that publishes the videos, where the publishing history is stored; on another machine, the script keeps the examples already in motores.json and regenerates the page with the new text.

1

Download the repository

You need Python 3 and git. ffprobe (from FFmpeg) is optional. It helps identify whether each video is 16:9 or 9:16.

git clone https://github.com/inematds/motores-de-video
cd motores-de-video
2

New video engine? Describe it in catalogo.json

Add the engine with the text in Portuguese and a rule that identifies its videos (source folder or channel). Use "excluir" to remove a video and "fixar" to choose one.

"regras": {"origem": ["/meu-motor/edicoes/"]}
3

Translate only what's new

The English and Spanish texts are in i18n/en.json and i18n/es.json. The script uses INEMA's central translator (the inema-traduz command, which is only available on INEMA's machine) for missing keys. Without it, write the translations by hand in those two files.

python3 traduzir.py
4

Reread the history and generate everything

It selects up to 3 recent, varied public videos per engine, saves motores.json, and regenerates the 3 READMEs and the 3 pages.

python3 atualizar-exemplos.py
5

Publish

Check the page and what changed, then send it. GitHub Pages publishes automatically from the main branch.

git status
git add -A && git commit -m "exemplos atualizados" && git push
