En resumen

Este repositorio es un índice: explica, en una página, cada motor que INEMA usa para producir videos: explicativos, reels, radares diarios y videos hechos con código. Sirve para quienes quieren saber qué motor usar o estudiar uno de ellos. Cada motor incluye qué hace, para qué tipo de video sirve, el formato, si usa avatar, cómo se activa, el enlace al código y hasta 3 videos reales publicados en YouTube. No hace falta instalar nada para leerlo.

Qué es

Un mapa de los motores, con pruebas

Aquí no se copia el código de ningún motor. Cada tarjeta apunta al repositorio del motor y a videos que ya produjo.

🗂️ Un índice, no un motor

Qué hace cada motor, en lenguaje sencillo, con formato, avatar y activación.

▶️ Hasta 3 ejemplos reales

Videos públicos, recientes y variados, tomados del historial de publicaciones: 56 videos de ejemplo en total.

🔄 Se actualiza con un script

Un comando vuelve a leer el historial y actualiza la lista de ejemplos, el README y esta página.

Palabras que aparecen en las tarjetas

Nei
Nei Maldaner, creador de INEMA. Su avatar (una versión digital que habla el guion) presenta la mayoría de los videos.
HeyGen
Servicio que genera el video del avatar hablando. INEMA usa el estudio del sitio con una suscripción.
inemaccbot
Bot de INEMA en Telegram que activa algunos motores con un comando, como /r7ex o /explicavideo.
Timer
Programación automática en la computadora que produce los videos: el motor funciona solo a la hora programada.
Cola
Lista de videos listos que se publican poco a poco, uno a la vez, en el horario indicado.
Skill
Paquete de instrucciones que enseña a Claude Code (o a Codex) a realizar un tipo de trabajo.
Traductor central
El comando de INEMA que hace todas las traducciones con la suscripción, sin una API de pago.
Historial de publicaciones
El registro que la herramienta de publicación en YouTube (yt-pubx) guarda cada vez que se envía un video.
Terminal y agente
El terminal es la ventana de comandos de la computadora; el agente es la IA (Claude Code o Codex) que funciona allí y ejecuta el motor cuando se lo pides.
Canales INEMA TDS, FTD, TIA, Tec…
Los canales de INEMA en YouTube; cada motor publica en el canal del tema (tecnología, finanzas, clima, deportes, aventuras).
INEMA.CLUB y PRO
INEMA.CLUB es el portal gratuito de cursos y proyectos de INEMA; PRO es el área con el catálogo y la búsqueda completos.

Para quien mantiene el índice · paso a paso

Cómo mantener esta página al día

Para solo leer la página, no hace falta instalar nada. Estos pasos son para quien mantiene el índice. Los ejemplos nuevos solo aparecen en la máquina que publica los videos, donde está el historial de publicaciones; en otra máquina, el script mantiene los ejemplos que ya están en motores.json y vuelve a generar la página con los textos nuevos.

1

Descarga el repositorio

Necesitas Python 3 y git. ffprobe (de FFmpeg) es opcional: ayuda a descubrir si cada video es 16:9 o 9:16.

git clone https://github.com/inematds/motores-de-video
cd motores-de-video
2

¿Motor nuevo? Descríbelo en catalogo.json

Agrega el motor con el texto en portugués y la regla que identifica sus videos (carpeta de origen o canal). Usa "excluir" para quitar un video y "fixar" para elegir uno.

"regras": {"origem": ["/meu-motor/edicoes/"]}
3

Traduce solo lo nuevo

Los textos en inglés y español están en i18n/en.json e i18n/es.json. El script usa el traductor central de INEMA (el comando inema-traduz, que solo existe en la máquina de INEMA) para las claves que faltan. Sin él, escribe la traducción a mano en esos dos archivos.

python3 traduzir.py
4

Vuelve a leer el historial y genera todo

Elige hasta 3 videos públicos, recientes y variados por motor, guarda motores.json y vuelve a generar los 3 READMEs y las 3 páginas.

python3 atualizar-exemplos.py
5

Publica

Revisa la página y los cambios, y envíalos. GitHub Pages publica automáticamente desde la rama main.

git status
git add -A && git commit -m "exemplos atualizados" && git push
